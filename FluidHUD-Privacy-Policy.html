1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные обрабатывает приложение FluidHUD и как они используются.

FluidHUD — локальный системный media-overlay для Windows 10 и Windows 11. Приложение не требует регистрации, не содержит рекламы и не использует облачные сервисы разработчика.

2. Данные, обрабатываемые приложением

FluidHUD обрабатывает только данные, необходимые для работы заявленных функций:

  • название текущего трека;
  • имя исполнителя и название альбома;
  • обложку трека;
  • состояние воспроизведения, позицию и длительность;
  • идентификатор приложения, предоставившего Windows media session;
  • состояние общей громкости и отключения звука;
  • пользовательские настройки: горячую клавишу, прозрачность, положение, время показа, скорость анимации и настройку автозапуска.

Медиа-данные предоставляются локальными API Windows — Global System Media Transport Controls и Windows Core Audio.

3. Цель обработки

Данные используются исключительно для отображения информации о текущем треке, выполнения команд Play/Pause, Previous, Next и Seek по прямому действию пользователя, отображения общей громкости, применения настроек и опционального запуска вместе с Windows.

4. Передача и продажа данных

FluidHUD не отправляет медиа-данные, настройки или диагностическую информацию на серверы разработчика или третьих лиц.

Разработчик не продаёт, не сдаёт в аренду и не передаёт пользовательские данные. В приложении отсутствуют аналитика, рекламные SDK, трекеры, cookies и телеметрия разработчика.

Microsoft Store и Windows могут самостоятельно обрабатывать сведения об установке, обновлении и стабильности приложения в соответствии с политикой конфиденциальности Microsoft. Разработчик FluidHUD не управляет этой обработкой.

5. Локальное хранение

Настройки и журнал необработанных ошибок могут храниться в локальном профиле пользователя:

%LocalAppData%\FluidHUD\settings.json
%LocalAppData%\FluidHUD\FluidHUD.log

Обложки кэшируются только в оперативной памяти и удаляются при завершении процесса. Локальные файлы сохраняются до удаления пользователем, очистки папки или удаления приложения.

6. Диагностический журнал

FluidHUD может создать локальный журнал при необработанной ошибке. Он содержит техническое описание исключения и не отправляется автоматически. Пользователь самостоятельно решает, передавать ли журнал при обращении в поддержку.

7. Разрешения и runFullTrust

FluidHUD использует runFullTrust для регистрации выбранной пользователем глобальной горячей клавиши, управления borderless/topmost окном, чтения локальной Windows media session, получения уведомлений Core Audio и выполнения пользовательских команд воспроизведения.

runFullTrust не используется для повышения прав администратора, установки служб или драйверов, записи звука, внедрения кода, чтения произвольных файлов или скрытого перехвата клавиатуры.

8. Автозапуск

Автозапуск выключен по умолчанию и включается только пользователем. Store/MSIX версия использует стандартный Windows StartupTask. Пользователь может отключить его в FluidHUD, Параметрах Windows или Диспетчере задач.

9. Дети

FluidHUD не предназначен специально для детей и сознательно не собирает персональные данные детей или иных пользователей.

10. Безопасность и права пользователя

Данные обрабатываются локально. Пользователь может отключить автозапуск, изменить настройки, удалить локальные файлы или прекратить обработку, завершив либо удалив FluidHUD. У разработчика отсутствует удалённая пользовательская база данных.

11. Изменения политики

Политика может обновляться при изменении функций FluidHUD или применимых требований. Актуальная версия публикуется по тому же адресу с новой датой вступления в силу.

12. Контакты

По вопросам конфиденциальности свяжитесь с CatYaderka через контактные данные поддержки на странице FluidHUD в Microsoft Store.

FluidHUD Privacy Policy

Effective date: August 10, 2026 · Version 1.0 · Developer: CatYaderka

1. Overview

FluidHUD is a local Windows 10/11 desktop media overlay. It requires no account, contains no advertising, and uses no developer-operated cloud services.

2. Information processed

FluidHUD processes only the active track title, artist, album, artwork, playback state, position, duration, source application identifier, master-volume state, and user-selected FluidHUD settings. This information is supplied locally by Windows GSMTC and Core Audio.

3. Purpose

The information is used only to display and control the active media session, show volume state, apply preferences, and optionally start FluidHUD with Windows when explicitly enabled.

4. Sharing and sale

FluidHUD does not transmit media information, settings, or diagnostics to developer or third-party servers.

The app contains no analytics, advertising SDKs, trackers, cookies, or developer telemetry. Microsoft Store and Windows may process installation, update, and reliability information under Microsoft's own privacy terms.

5. Local storage

%LocalAppData%\FluidHUD\settings.json
%LocalAppData%\FluidHUD\FluidHUD.log

Artwork is cached in memory only. Local files remain until deleted by the user, their folder is cleared, or the app is removed.

6. Diagnostics

An unhandled-error log may be created locally. It is never uploaded automatically. The user decides whether to inspect, delete, or voluntarily provide it to support.

7. Permissions and runFullTrust

runFullTrust is used for a user-selected global shortcut, the borderless/topmost desktop window, local Windows media sessions, Core Audio notifications, and user-requested playback commands. It is not used for administrator elevation, services, drivers, audio recording, code injection, arbitrary file access, or arbitrary keyboard capture.

8. Startup

Startup is disabled by default and enabled only by the user through the standard Windows StartupTask mechanism.

9. Children

FluidHUD is not specifically directed at children and does not knowingly collect personal information.

10. User choices

Users may disable startup, reset settings, delete local files, or stop all processing by closing or uninstalling FluidHUD. The developer maintains no remote user database.

11. Changes

The current policy will remain available at this URL with its effective date shown above.

12. Contact

For privacy questions, contact CatYaderka through the support information on the FluidHUD Microsoft Store page.
